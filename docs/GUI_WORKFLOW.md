# GUI 操作流程记录（Stage 0 基线）

> 本文档记录「七方视频封面批量制作」GUI 的当前操作流程，作为重构回归基线。
> 记录时间：2026-08-08（Stage 0）。此后每次重构需对照本文验证「用户可见行为未变」。

## 程序入口

- 源码运行：`python qifang_cover_maker.py`（需本机已装 Adobe Photoshop；tkinter 需系统 Python 3.14）
- EXE：双击 `七方视频封面批量制作.exe`（同上，需本机 Photoshop）

## 主界面

三个标签页：

1. **① 文件与字段**
2. **② 门店Logo映射**
3. **③ 生成**

窗口默认 820x760，可缩放；下方为运行日志区（只读滚动文本框）。

---

## ① 文件与字段 页

### 文件选择
- **PSD 模板**：输入框 + 「浏览...」按钮（文件类型过滤 *.psd）
- **Excel 数据**：输入框 + 「浏览...」按钮（*.xlsx *.xls）
  - 选择 Excel 后，若输出目录为空，自动生成默认输出目录：
    `Excel文件名_封面输出`（位于 Excel 同目录）
- **输出目录**：输入框 + 「浏览...」按钮

### 表头选项
- 复选框「Excel 首行为表头（数据从第2行开始）」
  - **默认：不勾选**（Stage 8 将改为默认勾选）

### 字段映射（选择 Excel 列）
- 下拉框（A..P）：
  - 门店列（用于选 Logo）默认 A
  - 姓名列默认 B
  - 电话列默认 D
  - 销售顾问列默认 C，多一个「（不替换）」选项
- 提示文案：「销售顾问列选「不替换」则保留 PSD 原文字。」

---

## ② 门店Logo映射 页

- 左侧：PSD 全部图层清单，每个图层一个复选框（勾选 = 该图层参与 Logo 处理）
  - 默认勾选启发式：图层名含 `logo`、父组名含 `logo`、或图层名 == Excel 门店名
  - 同时恢复上次保存配置里勾选的图层（含组，子层继承勾选）
- 右侧：门店 → Logo 图层 下拉映射表
  - 每行一个门店（来自 Excel 门店列，去重保序）
  - 下拉可选项 = 左侧勾选图层的「叶子图层」展开结果（组会自动展开为子层）
  - 自动匹配：门店名与图层名「互含」则自动填入；无匹配则留空（「（无）」）
  - 左侧勾选变化时，右侧下拉实时同步（已选值失效时重置为「（无）」）

---

## ③ 生成 页

- 输出格式：PNG / JPG / PSD 单选
- 同时导出 PNG：复选框（仅 PSD 格式时有效，额外多导出一张 PNG）
- **预览**按钮：用 Excel **第一条物理数据行**（`rows[start]`）生成一张 PNG 到
  `preview_tmp/preview.png` 并自动用系统默认看图程序打开
  - 注意：预览不经过「跳过空行」过滤（Stage 5 将改为第一条有效数据）
- **开始**按钮：启动 worker 线程批量生成
- **停止**按钮：设置停止标记，**每行之间**检查（当前行 Photoshop 操作不打断）
- 进度条 + 进度文字（已完成数/总数）
- 日志区实时输出进度与错误

---

## 配置保存与加载

- 配置文件：`qifang_cover_config.json`（与 exe / 源码同目录）
- 保存：③ 生成页「保存配置」按钮 → 把当前 UI 状态写入 JSON
  - 字段：psd/xlsx/out 路径、has_header、各列索引、text_map（姓名/电话/销售顾问图层名）、
    logo_layers（左侧勾选的图层名，**含组**）、store_logo_map（门店→图层名）、fmt、also_png
- 加载：启动时自动读取；把路径、列、text_map、logo 勾选与映射恢复到 UI
  - 恢复的 logo 勾选/映射在「加载」PSD 后作为默认值填入

---

## 加载 PSD 流程（① 页「加载」按钮）

1. 校验 PSD 与 Excel 路径存在
2. 读 Excel：按 **A 列固定**（忽略「门店列」设置）取去重门店列表 ——
   **已知问题 P1-01**（Stage 4 修复）
3. 通过 Photoshop COM 打开 PSD，递归收集图层名（去重保序）、文字图层名；立即关闭文档并退出 PS
4. 按启发式 + 旧配置恢复 Logo 勾选；自动匹配门店→Logo；自动匹配文字图层
5. 刷新 ② 页 Logo 列表与文字图层下拉

## 批量生成流程（③ 页「开始」）

1. 收集配置（① 页列设置、② 页 Logo 勾选与映射、③ 页格式）
2. 读 Excel（过滤空行/姓名为空/电话为空），每行处理：
   - 打开模板 PSD → `Duplicate()` 副本
   - 替换姓名 / 电话 / 销售顾问文字层
   - 按门店切换 Logo 可见性；品牌 Logo（名字含 logo 且未映射）强制显示
   - 按格式导出（PSD 格式时可选同时导 PNG）
   - 关闭副本
3. 处理完关闭模板；退出由本程序拉起的 Photoshop（`ps_cleanup(quit=True)`）
4. 日志输出：已生成 N/total、总耗时、输出目录

> 已知：预览（_preview）与批量（run_batch）是两套独立实现（P1-03）；
> 文字/Logo 写入失败目前为警告并继续（P0-05）；Logo 组与叶子数据模型不一致（P0-03）。

- [ ] 勾选一个 Logo，右侧下拉实时同步
- [ ] ③ 页点「预览」：生成 preview.png 并弹出查看
- [ ] ③ 页点「开始」：日志出现进度，输出目录出现 001_门店_姓名.png
- [ ] 点「停止」：每行之间停止，不再新开行
- [ ] 点「保存配置」后重开程序：路径/列/Logo 勾选与映射恢复
