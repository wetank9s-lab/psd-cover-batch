三、Worker 架构（#8-#17） ### 单一 worker 约束（#6/#8/#12） - `WorkerBase` 持有 `_worker_lock` + 单一 `_thread`（**非 daemon**，name=`task-worker`）。 - `start_task()`：已有 worker 存活 → `raise WorkerAlreadyRunningError`（GUI 入口与 worker 双重兜底）。 - 测试 `test_start_task_while_alive_raises` 验证。 ### Queue 事件模型（#9/#10/#19） `queue.Queue[WorkerEvent]`，11 种事件类型（`STATE/LOG/PROGRESS/ROW_STARTED/ROW_FINISHED/LOAD_DONE/PREVIEW_DONE/BATCH_DONE/WORKER_DONE/ERROR/CANCELLED`）。 **payload 红线**（#20/#21/#22）： - 只允许 `str/int/float/bool/Path/list/dict/dataclass/None`； - **禁止 COM object / Tk widget 入队**（测试 `test_event_payload_must_be_pure_python` 双层检查 + `test_worker_event_payload_never_com_object` 字段类型检查）； - Exception 先 string 化（`exception_to_error_payload` → `ErrorPayload`）； - `LoadResult` 的 LayerRef 序列化为 dict；`BATCH_DONE` 用 `batch_result_to_summary` 纯 dict。 ### 线程隔离保证（#11/#13/#14） | 红线 | 保证 | |---|---| | COM 只在 worker 线程创建/销毁 | 每个任务 `with PhotoshopSession()`（内部 `CoInitializeEx/CoUninitialize`），`com_dispatch=None` → renderer 在 worker 线程内 `Dispatch` | | SaveOptions 线程创建 | `_save_option(fmt, com_dispatch)` 每次新建，绝不模块级/实例缓存（Stage 5 CDispatch bug 根因已根治） | | worker 不碰 Tk | `gui_workers.py` grep 验证 **0 处** `tk./ttk./messagebox/StringVar/BooleanVar/winfo/config(` | | main 不碰 COM | `qifang_cover_maker.py` 中 `PhotoshopSession(` 仅存在于 CLI 遗留函数 `run_batch`（独立线程，v1.1.0 未改） | ### 任务快照（#13/#30） - main thread 在启动前收集纯 dict（`_snapshot_for_load` / `_collect_cfg()+_task`）； - worker 只读快照，绝不读 Tk variables； - 测试 `test_snapshot_is_pure_dict`（JSON 可序列化）+ `test_worker_reads_snapshot_without_tk`。 ### Worker 生命周期（#15/#16） - `_run_wrapper`：try → 异常兜底 ERROR 事件；finally → **先清 `_thread` 再发 WORKER_DONE**（调试期修正：原顺序导致 GUI 收到 WORKER_DONE 时 `worker_alive` 仍 True，`_maybe_destroy` 检查失败）+ `_worker_done_event.set()`； - `wait_worker_done(timeout)` 带超时返回 bool（不无限等）。 --- ## 四、Load / Preview / Batch worker（#23-#28） ### Load（#26） `TaskWorker._do_load`：Excel（纯 Python）→ PSD（worker 内 COM `collect_layer_index` + `serialize_ref`）→ `LOAD_DONE` 携带纯数据 `LoadResult`。main thread `_on_load_done` 用纯数据重建 `LayerIndex` + 全部 GUI 索引 + 文字下拉 + `_init_logo_checks`（推荐勾选/门店匹配/保存恢复）。 ### Preview（#25） `_do_preview`：Excel 校验 → 分组 preflight → worker 内 `PhotoshopSession` + `render_one(preview=True)` → `PREVIEW_DONE`。**`os.startfile`（用户可见动作）由 main thread 执行**。 ### Batch（#27/#28） `_do_batch`：Excel/分组 preflight → worker 内 COM → `renderer_run_batch(...cancel_event, progress_cb, com_dispatch=None)` → `BATCH_DONE`（结构化 summary）+ 完成日志 + 失败行明细。**单行失败 ≠ GUI ERROR**（回 READY，`#24`）。 ### 协作取消（#17/#18） - `request_stop()`：仅置 `cancel_event`（threading.Event），**不 kill 线程/不 kill Photoshop**； - renderer 循环顶部检查点：`if cancel_event.is_set(): break with cancelled=True`； - GUI `_stop()`：仅 `RUNNING→STOPPING→READY`（STOPPING 中 Stop 按钮禁用）； - 任务间 `cancel_event.clear()`（旧取消不泄漏）。 --- ## 五、安全窗口关闭（#29） ``` _on_exit (WM_DELETE_WINDOW) ├─ worker 未运行 → root.destroy()（立即） └─ worker 运行 → _pending_close=True request_close() # closing flag + cancel_event RUNNING→STOPPING 轮询继续（不 destroy） → worker 自然退出（WORKER_DONE） → _on_worker_done → _maybe_destroy → root.destroy() ``` - 绝不 `kill/terminate/os._exit`；绝不 worker 存活时 destroy； - 测试：`test_close_while_idle_destroys_immediately` / `test_close_while_worker_running_waits_for_worker_done` / `test_wait_worker_done_timeout_returns_false` / `test_cleanup_joins_without_kill`。 --- ## 九、调试期发现并修复的问题（#38 自查） 1. **`LOADING→IDLE` 转换缺失**：Load Excel 失败路径（fatal=False ERROR → WORKER_DONE）导致 `_on_worker_done` 尝试 `LOADING→IDLE` 被拒 → 按钮永久禁用卡死。修复：转换表允许 `LOADING→IDLE`。 2. **WORKER_DONE 与 `_thread` 清空顺序**：原 finally 先发 WORKER_DONE 再清 `_thread` → GUI 收到事件时 `worker_alive` 仍 True → `_maybe_destroy` 不销毁窗口。修复：先清 `_thread` 再发事件。 3. **UI 构建后控件未应用 IDLE 规则**：`__init__` 构建 UI 后按钮默认 normal，与状态机不符。修复：`_build_ui()` 后补 `_apply_controls(controls_for(IDLE))`。 4. **tkinter 8.6 `cget('state')` 返回 Tcl_Obj**：Python 3.14 行为差异，验收脚本断言需 `str()` 转换（非产品 bug）。 --- ##
